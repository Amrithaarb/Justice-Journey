# Justice Journey

### Interactive Legal Education Through Real-World Scenarios

Justice Journey is an interactive web application designed to simplify legal education and improve legal awareness through real-world scenario simulations. The platform helps users understand legal concepts, rights, and responsibilities through engaging, practical learning experiences.

## Objectives

- Make legal knowledge accessible and easy to understand.
- Promote awareness of laws and individual rights.
- Explain legal concepts through real-life situations.
- Encourage interactive and scenario-based learning.

## Key Features

- **Legal Awareness:** Learn about laws and legal responsibilities.
- **Scenario-Based Learning:** Explore practical situations to understand how laws apply.
- **Interactive Interface:** Engage with legal concepts through an intuitive platform.
- **Responsive Design:** Access the application across different devices.

## Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Build Tool:** Vite
- **UI Components:** Radix UI

## Installation

Clone the repository:

```bash
git clone https://github.com/Amrithaarb/Justice-Journey.git
```

Navigate to the project directory:

```bash
cd Justice-Journey
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
Once the server starts, access Justice Journey using:

Local: http://localhost:8080/

Open the local URL displayed in your terminal.
